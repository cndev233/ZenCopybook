# ZenCopybook (练字字帖生成器)

一个简单的桌面端字帖生成工具，基于 Python 和 PySide6 开发。支持自定义字帖格型、颜色、字体以及多页导出。用于在数位板或者数位屏上练字使用。

## 💡 主要功能

- **简单格型调整**：支持米字格、田字格、普通方格。
- **自定义色彩**：线条颜色和文字颜色可调整
- **字体导入**：支持导入外部 `.ttf` / `.otf` 字体文件。
- **排版与多页预览**：自动根据文本长度分页（单页 140 字），支持上下页预览。
- **PNG图片导出**：支持导出当前页或一键批量导出所有页面为高清 PNG 图片。
- **干净文本粘贴**：输入框自动过滤带有格式的文本（比如从网页复制的样式/背景色），方便直接练字。

## 🛠️ Quick Start (快速开始)

本项目使用 [uv](https://github.com/astral-sh/uv) 进行依赖和包管理。

### 运行项目
```bash
cd ZenCopybook
uv run zencopybook
uv run python -m zencopybook.main
```
